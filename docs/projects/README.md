# Project presentation revamp

Updated 2026-09-26. Implementation requirements and supporting design context.

## Objective and scope

The basic project view feels only slightly more detailed than the landing page:
a short personal introduction, one useful visual and clear public evidence.
Optional technical depth is available through Advanced mode.

Projects, About and Certificates share a dark horizontal masthead, straight cyan
border and white content. The landing keeps its distinct composition. Preserve
existing project IDs, ordering, direct links, approved assets and factual accuracy.
Restore verified public project links and use optional explicit GitHub-hosted
project icon assets. Paul's Timeline is excluded.
